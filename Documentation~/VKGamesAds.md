# Реклама VK Games

`VKGamesAdvProvider` реализует обычный `IAdvProvider` через VK Bridge.
Поддерживаются interstitial, rewarded и sticky-баннер. Для платформы, профиля
и паузы доступны [отдельные модули](Platform.md), для оплаты —
[ограниченный клиентский адаптер](InAppPurchases.md#vk-games--vk-bridge).

## Подключение

1. Обновите пакет UniWebKit в игре. При установке по Git URL локальные изменения
   репозитория нужно сначала доставить в используемую игрой версию пакета.
2. Выберите `VKGames` в `UniWebSettings`: редактор добавит `UNIWEB_VK_GAMES` для WebGL.
3. Используйте Static API или `builder.RegisterUniWeb()` для VContainer.
4. Соберите WebGL и проверьте рекламу внутри приложения VK.

Мост расположен в `Runtime/Providers/VKGames/Plugins/WebGL/UniWebVKBridge.jslib`.
Его `.meta` сохраняет исходный GUID и ограничивает импорт платформой WebGL.
Дополнительный `asmdef` для JavaScript не нужен; C#-адаптер входит в сборку UniWebKit.
Копии `.jslib` в `Assets` быть не должно, иначе в сборке будут одинаковые символы.

WebGL-шаблон остаётся в проекте игры. Страница может загрузить `TemplateData/vk-bridge.js`,
который добавляет UniWebKit при сборке. Мост загрузит тот же файл, если `window.vkBridge` ещё отсутствует.
Вызовом `VKWebAppInit` управляет мост.
Одновременные запросы разделяют загрузку и инициализацию на странице.
Ошибка или неподтверждённый результат инициализации не считаются успехом.

```csharp
var ads = UniWebBridge.Ads; // Или IAdvProvider через DI.
if (ads.IsRewardedReady)
{
    ads.ShowRewarded(onReward: GiveReward, onClosed: success => RefreshButton());
}
```

`GiveReward` и `RefreshButton` здесь — методы игры. При вызове через конкретный
класс также используется стандартное имя аргумента `onReward`.

## Поведение

- В Editor и вне WebGL провайдер безопасно сообщает отсутствие поддержки.
  Показ завершается ошибкой и `onClosed(false)`, награда не выдаётся.
- `IsSupported` требует успешной инициализации и поддержки рекламных методов
  мостом; само наличие браузера не означает поддержку рекламы.
- `IsInterstitialReady` / `IsRewardedReady` отражают подтверждённый результат
  `VKWebAppCheckNativeAds`. Проверки запускаются при инициализации, после показа
  и при чтении готовности с интервалом не менее пяти секунд. Пока проверка
  не завершилась или реклама отсутствует, значение — `false`.
- По явному запросу `ShowRewarded` адаптер обращается к VK Bridge даже при отрицательном результате
  предыдущей проверки. Наличие рекламы и выдачу награды определяет ответ на фактический показ.
- Между экземплярами разрешён только один полноэкранный показ. Rewarded выдаёт
  награду только после `result === true`; отмена, `false` и ошибка не награждают.
- У используемого API нет отдельного уведомления о фактическом открытии рекламы.
  `onOpened` вызывается непосредственно перед отправкой команды показа, чтобы
  игра могла заранее приостановиться. Отказ SDK затем закрывает этот сценарий
  через `onError` и `onClosed(false)`.
- При использовании без VK-провайдера паузы адаптер приостанавливает звук и затем
  восстанавливает прежнее значение `AudioListener.pause`. `Time.timeScale`
  он не меняет. Когда VK-провайдер паузы создан, управление звуком передаётся игре
  через `IPauseProvider`, чтобы закрытие рекламы не отменяло другую причину паузы.
  Исключение в игровом callback не препятствует завершению остальных.
- Баннер запрашивается с `bottom` / `resize`. Ошибки его показа не награждают
  игрока и не меняют состояние полноэкранного показа.
- `IsAdBlockEnabled` — эвристика по скрытому DOM-элементу, не проверка рекламного инвентаря.
- `placementId` сохраняется в общем контракте rewarded, но этот API VK его не принимает.

## Освобождение

Провайдер реализует `IDisposable`. VContainer управляет singleton, а Static API
освобождает прежний рекламный провайдер при замене, если тот реализует `IDisposable`.
Повторная передача того же экземпляра его не уничтожает.

Освобождение во время рекламы завершает игровые callbacks ошибкой и
`onClosed(false)`, восстанавливает звук и отсоединяет их от будущего результата.
Сам нативный показ отменить нельзя: общая очередь остаётся занятой до ответа SDK.
Поздний успех не награждает игрока и не попадает следующему провайдеру.
Таймаута, разрешающего второй показ при неизвестном результате первого, нет.

## Проверки

`Tests~/VKAds` содержит проверки JS-моста с двойником VK Bridge и управляемые
проверки C#-колбэков, звука и освобождения. `link-smoke.c` проверяет реальные
зависимости `.jslib` при линковке установленным Unity Emscripten.
Эти проверки не вызывают рекламный сервис. Реальные объявления, доступность
инвентаря и поведение баннера проверяются внутри приложения VK перед выпуском.
